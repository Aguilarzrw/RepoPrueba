# NÓRDEN — Demo de catálogo digital de aguidev

Proyecto ficticio e independiente para demostrar un catálogo digital comercial.

## Funciones incluidas
- Catálogo adaptable a móvil y escritorio.
- Búsqueda, categorías y ordenamiento.
- Fichas de producto y disponibilidad de muestra.
- Bolsa y simulación de pedido (sin pagos ni envío real).
- Panel de demostración para añadir productos y modificar existencias.
- Persistencia local mediante localStorage.
- Diseño y contenido ficticios; no utiliza identidad, marcas ni datos de RepoPrueba.

## Ejecutar
Abrir `index.html` en un navegador o servir la carpeta con cualquier servidor estático.

## Nota
Los importes, inventario, productos y pedidos son datos de muestra. Las imágenes se cargan desde Unsplash. No existe backend, autenticación ni procesamiento de pagos en esta demo.
